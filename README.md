# dcl-cat-kit

Living cats for Decentraland SDK7 scenes: they follow a daily routine, walk your floors and stairs, come when called,
purr when petted, say hello when you arrive, and curl up by you when you sit.

Work in progress (part 1 of 5). See `packages/cat-kit/README.md`.
